# Wattly

Track your dorm's electricity use. Log devices (watts × hours) or meter readings, set your price per kWh, and see kWh and cost for today, this week or this month. Everything is stored on your device only.

Built with Flutter. Web version: https://c4rlosst.github.io/wattly/ — open it on your phone and use "Add to Home Screen".

```
flutter pub get
flutter test
flutter run -d chrome
```
